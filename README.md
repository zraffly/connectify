# Connectify

Версия Артура. Самостоятельная вёрстка на HTML, CSS и JavaScript без фреймворков и сборщика.

## Запуск

Можно открыть `login.html` двойным щелчком. Для проверки всех сценариев с сохранением данных рекомендуется локальный сервер:

```sh
python -m http.server 8000
```

Выполните команду из этой папки и откройте http://localhost:8000/login.html.
На Windows при установленном Python можно запустить `start.bat`.
Для просмотра канала без входа откройте `channel.html`. Серверная авторизация для просмотра не требуется.

Можно зарегистрировать собственный локальный аккаунт. Данные сохраняются только в этом браузере.

## Структура

```text
css/
  components.css  Типографика, переменные тем и переиспользуемые компоненты
  layout.css      Каркас приложения, страницы и адаптивность
  design.css      Оформление этой версии
js/
  theme.js        Применение темы до отрисовки страницы
  app.js          Интерактивные сценарии
img/             Локальные SVG и демонстрационные вложения
fonts/           Inter Variable и лицензия SIL OFL
```

Все пути относительные. Папку можно перенести целиком; зависимости от соседнего проекта нет.
Иконки встроены в HTML как inline SVG; оригиналы в `img`. Шрифт подключается из `fonts`, сетевые запросы к Google Fonts не нужны.

## Адаптивность и темы

- От 1280 px: боковая панель и рабочая область.
- От 768 до 1279 px: панель скрыта и открывается кнопкой меню поверх страницы.
- До 768 px: одна колонка и нижняя навигация.
- На телефоне меню настроек становится горизонтальным, поля формы идут в одну колонку, брендовая панель входа скрывается, тред занимает рабочую область целиком, участники в шапке скрываются.

Светлая тема используется по умолчанию. `data-theme="dark"` на теге `html` меняет фон, панели, текст, границы и акценты. Выбор сохраняется в localStorage.

## Проверка интерактивности

Сообщения отправляются по Enter. Shift + Enter добавляет строку. Поддерживаются `**жирный**`, `*курсив*`, обратные кавычки для кода и `~~зачёркнутый~~`.
При вводе @ появляется список коллег; работают стрелки и Enter. В меню сообщения доступны копирование и действия со своими сообщениями.
Кнопка скрепки прикрепляет локальный файл до 2 МБ. Аватар принимается до 5 МБ и уменьшается перед сохранением.
Поиск находит примеры и новые сообщения из каналов и личных переписок. Ctrl + K или Cmd + K открывает поиск.
Демонстрационный код приглашения: `CONNECT2026`.

Это клиентская учебная работа. Реального обмена сообщениями между устройствами, почтовой рассылки и OAuth Google нет. Кнопки восстановления и Google открывают соответствующее пояснение. Пароль локального аккаунта сохраняется в виде SHA-256, исходный пароль не записывается. Для настоящего сервиса необходим сервер.
